# Интерактивный компонент тестирования ЕНТ (U-Study / UBD Style)

Готовый адаптивный модуль страницы тестирования Единого национального тестирования (ЕНТ) Республики Казахстан по предмету **«Математическая грамотность / Математика»**.

---

## 🚀 Варианты запуска

### Вариант 1. Моментальный запуск без установки (Zero Setup)
Просто откройте файл `index.html` двойным щелчком мыши в любом современном браузере (Chrome, Edge, Firefox, Safari).
- Не требует установки Node.js или npm.
- Все библиотеки (React 18, Babel, Tailwind CSS) загружаются автоматически через быстрый CDN.

### Вариант 2. Запуск через Node.js / Vite
1. Установите зависимости:
   ```bash
   npm install
   ```
2. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```
3. Откройте адрес `http://localhost:3000` в браузере.

## 🎯 Реализованный функционал

1. **Шапка (Header)**:
   - **Таймер обратного отсчета** на 120 минут (`120:00` $\to$ `MM:SS`). Динамическая цветовая индикация:
     - Обычный режим (зеленый/спокойный синий).
     - Менее 10 минут: предупреждающий янтарный.
     - Менее 5 минут: пульсирующий красный.
   - **Название предмета** со статусом «Идет экзамен».
   - **Индикатор прогресса**: счетчик «Вопрос X из 40» и анимированный progress bar.
   - **Встроенный калькулятор ЕНТ**: всплывающее окно для математических расчетов.
   - **Регулировка размера шрифта**: кнопки `A-`, `A`, `A+`.

2. **Панель навигации (Карта вопросов 1–40)**:
   - Сетка из 40 кнопок с моментальным переходом к любому вопросу.
   - **Цветовые состояния**:
     - *Зеленый*: отвеченные задания.
     - *Серый*: пропущенные / неотвеченные.
     - *Синий фокус*: текущий активный вопрос.
     - *Желтый бейдж/точка*: вопросы, помеченные флажком «В закладки».
   - **Фильтрация**: быстрый отбор по категориям «Все», «Отвеченные», «Пропущенные», «В закладках».
   - **Мобильная шторка**: удобная выезжающая панель навигации на экранах смартфонов.

3. **Блок вопроса**:
   - Формулировка задания с категорией темы и указанием баллов (1 балл).
   - 4 радио-кнопки (A, B, C, D) с крупной областью клика и визуальной подсветкой.
   - **Горячие клавиши**: клавиши `1`, `2`, `3`, `4` или `A`, `B`, `C`, `D` для выбора ответа; стрелки `←` и `→` для перехода между вопросами.
   - Кнопка сброса выбора ответа.
   - Кнопки навигации «← Назад», «В закладки», «Далее →».

4. **Завершение и результаты (Score & Detailed Review)**:
   - **Модальное окно подтверждения**: показывает количество отвеченных, пропущенных и помеченных вопросов, предупреждая, если остались нерешенные задачи.
   - **Экран итогов**:
     - Итоговый балл (например, 36/40) и процент выполнения.
     - Затраченное время.
     - Детальный разбор каждого вопроса: правильный вариант, ваш выбор, полный текст математического решения и обоснование ответа.
     - Кнопка «Пройти тест заново» для повторной тренировки.
