# EdTech Платформа подготовки к ЕНТ (11 класс)

Масштабируемая образовательная платформа для подготовки к Единому национальному тестированию (ЕНТ) Республики Казахстан с поддержкой двух языков (`kk` / `ru`), декларативным конфигуратором предметов и специализированным модулем **«Работа над ошибками» (Қатемен жұмыс)**.

---

## 🏛️ 1. Архитектура и модули

### 1.1 Языковая поддержка (i18n)
- Полная локализация интерфейса и тестового банка на **казахский (`kk`)** и **русский (`ru`)** языки.
- Мгновенное переключение языка в Header (`KZ` / `RU`) без перезагрузки страницы.
- Автоматическая подгрузка вопросов на выбранном языке с сохранением прогресса.

### 1.2 Конфигуратор предметов (`SUBJECTS_CONFIG`)
Все предметы, темы и профильные связки вынесены в декларативный файл [`src/config/subjectsConfig.js`](file:///c:/Users/nuras/Desktop/ЕНТ%20сайт%20подготовка/src/config/subjectsConfig.js). Добавление новых предметов не требует изменений в бизнес-логике.

- **Обязательные предметы (3 предмета / 40 вопросов):**
  1. История Казахстана / Қазақстан тарихы (20 вопросов)
  2. Грамотность чтения / Оқу сауаттылығы (10 вопросов)
  3. Математическая грамотность / Математикалық сауаттылық (10 вопросов)
- **Профильные комбинации (по 2 предмета / 70 вопросов):**
  - Математика + Физика
  - Биология + Химия
  - География + Всемирная история
  - Иностранный язык + Всемирная история
  - Казахский язык + Казахская литература

### 1.3 Спецификация данных вопросов (JSON Schema)
Каждый вопрос строго соответствует спецификации:
```json
{
  "id": "q101",
  "subjectId": "history_kz",
  "topicId": "kazakh_khanate",
  "language": "ru",
  "question": "В каком году образовалось Казахское ханство согласно Мухаммеду Хайдару Дулати?",
  "options": ["1465–1466 гг.", "1511–1512 гг.", "1723–1725 гг.", "1991 г."],
  "correctIndex": 0,
  "explanation": "Согласно 'Тарих-и Рашиди' Мухаммеда Хайдара Дулати, откочевка Джанибека и Керея положила начало ханству в 1465–1466 гг."
}
```

### 1.4 Модуль «Работа над ошибками» (Mistakes Review & Drill)
Отдельный раздел в личном кабинете ученика:
- **Многоуровневая фильтрация**: по предмету, кодификатору темы и статусу ошибки (*«Требует повторения»* / *«Исправлено»*).
- **Интерактивный разбор**:
  - Текст вопроса.
  - Ошибочный ответ ученика (выделен красным).
  - Правильный эталонный ответ (выделен зеленым).
  - Методическое объяснение (выдержка из учебника, формула, исторический источник).
- **Режим «Пройти заново» (Retest Mode)**:
  - Запуск экспресс-теста исключительно по ошибкам.
  - При верном решении статус автоматически меняется на «Исправлено».

## 📂 Структура файлов проекта

```text
├── index.html                           # Автономное SPA-приложение (запуск двойным кликом)
├── package.json                         # Конфигурация npm
├── vite.config.js                       # Конфигурация сборщика Vite
├── tailwind.config.js                   # Настройки Tailwind CSS
└── src/
    ├── config/
    │   └── subjectsConfig.js            # SUBJECTS_CONFIG: обязательные и профильные предметы
    ├── i18n/
    │   └── translations.js              # Словарь переводов (kk / ru)
    ├── data/
    │   ├── bilingualQuestions.js        # База вопросов по JSON-схеме (ru / kk)
    │   └── questionsData.js             # Дополнительный банк 40 вопросов по математике
    ├── components/
    │   ├── EntPlatform.jsx              # Корневой контейнер EdTech-платформы
    │   ├── Header.jsx                   # Шапка с переключателем языка и вкладками
    │   ├── ProfilePicker.jsx            # Выбор профильных предметов
    │   ├── TestSimulator.jsx            # Симулятор тестирования ЕНТ
    │   ├── MistakesReview.jsx           # Страница «Работа над ошибками»
    │   └── RetestModal.jsx              # Модальный экспресс-тест по ошибкам
    └── App.jsx                          # Точка входа React
```

## 🚀 Запуск проекта

### Вариант 1. Моментальный запуск (Zero Setup)
Откройте [`index.html`](file:///c:/Users/nuras/Desktop/ЕНТ%20сайт%20подготовка/index.html) двойным кликом мыши в любом браузере. Все функции (переключение языка, выбор профилей, тестирование и разбор ошибок) работают автономно без npm.

### Вариант 2. Запуск через Vite
```bash
npm install
npm run dev
```
